# M2-23 — Hive-partitioned directories

**Status:** todo
**Depends on:** M1-13, M2-13
**Crates:** `datascript-compiler`, `datascript-datafusion`, `datascript-fixtures`
**Diagnostic codes:** DS1085–DS1089 (names), DS3075–DS3079 (sources) (D-018)

## Goal
`from 'data/year=*/month=*/*.parquet'` exposes `year` and `month` as columns, as DuckDB users
expect. Decide Q-006 first and record the answer in DECISIONS.md.

## Scope
- Proposed answer to Q-006 (confirm or change it in the task): `key=value` path segments are read
  as partition columns automatically, for every format, and `read_*(…, hive = false)` turns this
  off. Add `hive` to `source::READERS` so the binder checks it like the other options (D-041).
- **Which segments count.** Only the directory segments written in the source path itself are
  inspected, never the base directory the path is resolved against (the script's directory, the UI
  root) or anything above it, so a checkout under `/tmp/run=1/` does not add a `run` column to
  every query. A single path counts too, as in DuckDB: `from 'data/year=2024/a.parquet'` has a
  `year` column. A `key=value` segment the user wrote in an absolute path counts, because they
  wrote it; `hive = false` is the way out. Write the rule into LANGUAGE.md §3.1.
- Partition column types are inferred from the values across all matches: `long`, then
  `datetime` (date-like values), otherwise `string`. `getschema` shows them after the file columns.
- A partition key that is also a column inside the files is an error from this task's names block,
  with help to rename one or set `hive = false`.
- Files whose paths do not all have the same keys (one file under `year=2024/`, one directly under
  `data/`) get a source error from this task's block naming both paths.
- Filters on partition columns prune files before they are opened (DataFusion's `ListingTable`
  supports partition columns and pruning; check it still works with per-file scans used for glob
  merging, M1-08).
- Fixtures: a small partitioned Parquet tree and a partitioned CSV tree under `tests/data/`
  (generated by `datascript-fixtures`).
- Update LANGUAGE.md §3.1 and move Q-006 from "Proposed" to a decision.

## Acceptance criteria
- [ ] Golden `run` cases: partitioned Parquet and CSV, `where year == 2024` over partitions,
      `hive = false`, and a key that clashes with a file column.
- [ ] A test (unit or `explain`) shows that a filter on a partition column skips other partitions.
- [ ] Works in WASM over registered file names (`registerFile('data/year=2024/a.parquet', …)`), or
      the gap is carried over to M5-01.
