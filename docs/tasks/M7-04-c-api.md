# M7-04 — C API

**Status:** blocked: waiting for a consumer. A stable C ABI is a long-term promise, and nothing
planned uses it yet (Python binds Rust directly, Node uses WASM). Unblock it when a binding for
another language (Go, R, Java, …) is planned or a user asks, and then check that the surface
below fits that consumer.
**Depends on:** M2-11, M2-13, M7-05
**Crates:** `datascript-capi` (new), `datascript-engine`, `datascript-datafusion`
**Diagnostic codes:** none (panics at the boundary are DS9001)

## Goal
A stable C ABI so other languages (Go, Java via Panama or JNI, R, C/C++, .NET, Zig) can embed
DataScript without each needing its own Rust binding crate. The Python package (M7-03) binds Rust
directly and does not use this.

## Scope
- A `cdylib` and `staticlib` with a header generated by cbindgen and committed (CI fails if it is
  stale).
- Surface (names are a proposal):
  - `ds_session_new(options)` / `ds_session_free`; options include the base directory.
  - `ds_session_register_path(session, name, path)` and
    `ds_session_register_stream(session, name, ArrowArrayStream*)` for host tables, through M7-05.
    An Arrow C stream can be read only once, but `check`, `run`, self-joins and later queries read a
    table many times: registration consumes the stream at once, materializes it in memory, and
    releases it. The header says the caller must not use the stream afterwards.
  - `ds_check(session, text, &diagnostics)`: diagnostics as JSON, the same format as
    `ds check --diagnostics json`.
  - `ds_run(session, text, &run)` then `ds_run_next(run, &stream)` yielding one
    `ArrowArrayStream` per query statement (the Arrow C Stream Interface), over `RunStream`
    (D-055). Releasing a stream or the run cancels it.
  - `ds_diagnostics_json`, `ds_diagnostics_free`, `ds_string_free`, `ds_version`.
- Ownership: everything DataScript returns has one matching free function; the header documents
  who owns each pointer. Errors are a status code plus a diagnostics handle. Every entry point
  catches panics and returns DS9001; nothing unwinds into C.
- Threading: say which handles may be used from several threads (a session is `Send + Sync`,
  D-011) and how the tokio runtime is owned.
- AGENTS.md allows `unsafe` only in the WASM crate. Record in DECISIONS.md that this crate is the
  second exception, and give every `unsafe` block a `// SAFETY:` comment.
- An ABI and versioning policy in ARCHITECTURE.md (what may change in a minor release).
- Shipping the library and header with releases is M6-02's (already in its "Carried over").

## Acceptance criteria
- [ ] A C smoke test built and run in CI: open a session, check a script with an error, run a
      query, read the Arrow stream, free everything. Run it under a sanitizer or Valgrind on Linux.
- [ ] Tests for cancellation, a panic converted to DS9001, and a registered host table.
