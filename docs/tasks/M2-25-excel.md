# M2-25 — Excel reader and writer

**Status:** todo
**Depends on:** M1-13, M2-09, M2-13, M2-26
**Crates:** `datascript-syntax`, `datascript-compiler`, `datascript-engine`, `datascript-datafusion`, `datascript-fixtures`, `editors/vscode`
**Diagnostic codes:** DS3080–DS3089 (D-018)

## Goal
`from 'budget.xlsx'` and `from read_xlsx('budget.xlsx', sheet = "Q3", range = "A1:F200")` read
Excel workbooks, as DuckDB's excel extension does.

## Scope
- Add `.xlsx` to the formats by extension (LANGUAGE.md §3.1) and `read_xlsx` to
  `source::READERS`, with options `sheet` (name; default the first sheet), `range` (A1 notation),
  `header` (bool, default true) and `schema` (from M2-09).
- `datascript-syntax` has its own `pub const READERS` (`crates/datascript-syntax/src/lib.rs`), and
  a test in `datascript-compiler` checks it agrees with `source::READERS`: add `read_xlsx` (and
  `write_xlsx` to the writer list) in both, and to the TextMate grammar in `editors/vscode` if it
  highlights reader names.
- Use `calamine` (pure Rust, so the wasm32 check still passes). Check its license and add it with
  the minimum features.
- Infer each column's type from its cells: `bool`, `long`, `real`, `datetime` (Excel dates),
  otherwise `string`. Mixed columns widen per LANGUAGE.md §4.2, or fall back to `string`.
- Globs over `.xlsx` merge by column name, as for other formats.
- Source errors from this task's block: unknown sheet (did-you-mean over sheet names), invalid
  range, password-protected or corrupt workbook. `.xls` and `.xlsb` are DS3002 with help, unless
  calamine reads them for free (then decide, and document it).
- Writing: `write_xlsx` in M2-26's writer catalog and `.xlsx` as an output extension, using
  `rust_xlsxwriter` (pure Rust; check its license, and turn off default features that call
  `SystemTime::now()` or pull in native compression, so the `wasm-datafusion` check still passes). Options: `sheet` (default
  `Sheet1`) and `header` (default true). `datetime` and `timespan` get Excel number formats.
  Values Excel cannot hold (a string over 32 767 characters, more than 1 048 576 rows) are an error
  from this task's block naming the limit, never silent truncation.
- A fixture workbook generated by `datascript-fixtures`, or a small committed `.xlsx` if it cannot
  be generated deterministically.

## Acceptance criteria
- [ ] Golden `run` cases: default sheet, named sheet, range, no header, a date column, a mixed
      column, and a `schema` override.
- [ ] Golden `run` cases that write a workbook with `output` and read it back with `read_xlsx`,
      including dates, a custom sheet name and no header.
- [ ] Golden error cases for each new code, including the row limit on write.
- [ ] `datascript-datafusion` still passes its wasm32 check.
